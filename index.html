⚡ ElectroLab

AC & DC Virtual Circuit Construction Laboratory

How to use

  1. Drag an apparatus from the left toolbox.
  2. Move the apparatus anywhere in the simulator.
  3. Select it to open Component Properties.
  4. Use ↶ / ↷ to rotate it.
  5. Drag directly from one terminal to another.
  6. Press START SIMULATION.

Keyboard

Delete → Remove selected component
Space → Start / pause simulation
R → Reset simulation
Q → Rotate left
E → Rotate right
